# TrackFlow frontend

Responsive React and TypeScript interface for the TrackFlow backend.

```powershell
npm.cmd install
npm.cmd run dev
```

The application expects the API at `http://127.0.0.1:8000/api/v1`. Override it with
`VITE_API_BASE_URL` in a local `.env` file. Run `npm.cmd run build` for a production build.
